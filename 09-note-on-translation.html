Syncca — Note on translation

Appendix item 9.

The study was carried out in the conversations’ original languages. Syncca’s transcripts are mostly Hebrew, with some English; the two raters read them in the original and produced their coding in a mix of Hebrew and English. Every coding decision — each event count and each overall code — was made on that original-language material.

This appendix is written in English. Where it quotes Hebrew — a line from a transcript, or a passage from a rater’s coding — the English is a translation made by Claude and verified by the author, a native Hebrew speaker who conducted the study. The translations are therefore downstream of the measurement: no coding decision rests on them, and a translation error could change only how a quoted example reads here, never a reported number.
